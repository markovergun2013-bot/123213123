# Aura Home 1.3.1

Тестовый лаунчер для Android 10+, включая Android 13. Это новый главный экран, а не прошивка.

## Управление

Откройте APK на телефоне и установите поверх предыдущей версии.

- Откройте «Все», удерживайте приложение → «На главный экран». В разделе «Мои приложения» удерживайте и перетаскивайте значки друг на друга. Порядок сохраняется. Для удаления перетащите значок на полосу удаления. Служебные кнопки и док пока фиксированные.
- Удерживайте часы или свободное место, либо нажмите «Обои и виджеты». Можно добавить Android-виджет и подтвердить доступ в системном диалоге. Виджеты располагаются вертикально. Кнопка под виджетом меняет высоту или убирает его.
- Четыре градиентных фона доступны статично или с анимацией световых пятен внутри Aura. Анимация останавливается при потере фокуса.
- На коротком рабочем столе работают свайпы вверх/вниз. С виджетами или большим числом значков жест прокручивает страницу: используйте кнопки «Все» и «Управление».
- «Обычный телефон» открывает прежний лаунчер. Для постоянного возврата смените главный экран по умолчанию.

## Обновления

Источник: https://github.com/markovergun2013-bot/123213123/releases/latest

В Aura откройте **Настройки → Обновления** и разрешите уведомления. Проверка запланирована раз в час; Android может задерживать её ради экономии энергии. Это не мгновенные push-уведомления. После принудительной остановки нужно снова открыть Aura. Установку APK подтверждает пользователь.

Версии до 1.3 не умеют проверять обновления. Установите 1.3.1 вручную один раз для подключения нового канала.

Автору: распакуйте комплект и запустите `Publish-Update.bat`. При первом запуске он установит официальный GitHub CLI при необходимости и попросит войти в GitHub. Для следующего релиза нужны новый APK с увеличенным versionCode, тот же ключ подписи и соответствующий release.json. Сам .bat не меняет код приложения и не превращает старый APK в новую версию.

## Проверки

Код скомпилирован, подпись APK проверена. На телефоне или эмуляторе новые функции ещё не проверены. Системная шторка, экран блокировки и чужие приложения не заменяются.

Сеть используется для GitHub Releases. Приложение не отправляет список приложений, фото, контакты или местоположение. GitHub видит обычные сетевые сведения запроса. Яркость и уведомления требуют необязательных разрешений.

## Сборка

Android Studio, SDK 35, AGP 8.7.3, Gradle 8.10.2, JDK 17/21; внешних библиотек нет. Команда: `gradle :app:assembleDebug`. Ключ опубликованных APK не входит в исходники. Сборка с другим ключом не установится поверх существующей.

Справка: [Android widgets](https://developer.android.com/develop/ui/views/appwidgets/host), [JobScheduler](https://developer.android.com/reference/android/app/job/JobInfo.Builder), [GitHub Releases](https://cli.github.com/manual/gh_release_create).
